# Архитектура

[English](../en/architecture.md)

| Область | Ответственность |
| --- | --- |
| YandexTrackerClient / IYandexTrackerClient | Точка входа, группы API, владение HTTP |
| Endpoints | Публичные интерфейсы и внутренние адаптеры запросов |
| Models | Модели обмена и дополнительные поля задач |
| Http | Авторизация, запросы, повторы, страницы и ошибки API |
| Serialization | Настройки JSON и формат временных меток Трекера |
| Exceptions | Типы ошибок HTTP и десериализации |
| YandexTrackerDuration | Преобразование рабочих длительностей |

Зависимостей от Alva и ASP.NET нет. Пакет не имеет runtime-зависимостей NuGet.
MinVer и SourceLink — приватные зависимости сборки. Публичный API документирован английскими
XML-комментариями. Модели используют System.Text.Json; дополнительные поля сохраняют нетипизированные данные.

Alva использует пакет через Alva.Integrations.YandexTracker. Модуль отвечает за сопоставление импорта,
конфигурацию/доступы, внешние идентификаторы и преобразование зависимостей. SDK отвечает за протокол Трекера.
Задачи SDK ставятся в проект YandexTracker в Aiko, поведение Alva — в Alva.

Реализована полезная часть официального Python-клиента, не весь его API.
Вложения, доски, пакетные операции, экспорты и получение токенов не реализованы.
