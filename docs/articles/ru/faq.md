# Вопросы и ответы

[English](../en/faq.md)

## Это официальный SDK?
Нет. Это независимый .NET-клиент с набором endpoints из README.
Поведение сервиса описывает [официальный справочник](https://yandex.ru/support/tracker/ru/api/about-api).

## Почему пропущены четыре теста?
Читающим тестам живого API нужны YANDEX_TRACKER_TOKEN и YANDEX_TRACKER_ORG_ID.
Unit-тесты всегда работают без сети. Корневой .env читают только тесты.
CI не передаёт живые доступы.

## Почему не восстанавливается 0.1.0?
Сначала пакет нужно опубликовать в NuGet. До этого соберите его и используйте временный локальный
источник: [Выпуск](releasing.md). Локальные пути и бинарники не коммитятся.

## Как прочитать дополнительные поля?
Issue.Fields содержит JsonElement неизвестных свойств. Читайте их согласно схеме поля.

## Поддерживается Native AOT?
Это не проверено. Сериализация использует reflection; совместимость с AOT/trimming не заявлена.

## Куда ставить задачи?
Ошибки SDK и предложения по его развитию оформляйте в репозитории YandexTracker.
