# Changelog

[Русский](CHANGELOG.ru.md)

## Unreleased

### Added

- Runnable read-only quick-start sample with configuration validation, cancellation and error handling.
- Standalone SDK targeting .NET 8, 9 and 10.
- Issues, searches, links, comments, transitions, queues, users and statuses.
- OAuth/IAM, organization headers, cancellation, pagination and safe retries.
- Typed API errors, working-time durations and extensible issue fields.
- English XML reference and English/Russian usage guides.

### Changed

- Updated English/Russian getting-started guides; the API reference now distinguishes SDK errors
  from standard transport, argument and cancellation exceptions. Public API and wire behavior are unchanged.
